# SVG: промпт-контракт для генерации

Верни **только полный SVG-документ**: от открывающего `<svg>` до закрывающего
`</svg>`. Не добавляй Markdown, пояснения или кодовые блоки.

## Обязательно

- SVG должен быть корректным XML и иметь один корневой элемент `<svg>` в
  пространстве имён `http://www.w3.org/2000/svg`.
- У корня должен быть `viewBox` из четырёх чисел, с положительными шириной и
  высотой. Предпочтительный холст: `viewBox="0 0 500 500"`.
- Не используй JavaScript, обработчики событий (`on...`), HTML,
  `foreignObject`, `iframe`, внешние URL и сетевые ресурсы.
- Не ссылайся на внешние файлы. Если используется ссылка по ID, она должна
  вести на элемент этого же SVG.
- Сохраняй текущие элементы и их `id`, если они всё ещё имеют тот же смысл.
  Новому элементу дай новый уникальный `id`
## Желательно для редактирования

**ВАЖНО: правила ниже не являются ограничением художественных возможностей SVG. Если нужный визуальный
результат требует другого безопасного SVG-тега, атрибута или определения,
используй его**

- Разбивай композицию на логические слои: фон, иллюстрация, текст, декор.
  Для группы или элемента можно добавить `data-name` с коротким названием.
- Предпочитай элементы `g`, `rect`, `circle`, `ellipse`, `line`, `path` и
  `text`.
- Используй обычные SVG-атрибуты геометрии и оформления (`fill`, `stroke`,
  `opacity`, `font-*`, `transform`), а не CSS в `<style>`.
- Для перемещения, поворота и масштаба используй `transform`.
- Для текста используй простой `<text>` без вложенных тегов; задай `x`, `y`,
  `font-size` и `font-family`.
- Градиенты размещай в `<defs>` как `linearGradient` или `radialGradient` со
  `stop` и локальной ссылкой вида `url(#gradient-id)`.
