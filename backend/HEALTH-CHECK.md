## Адрес
 
```
http://51.250.38.122:8080
```
 
## Как проверить вручную
 
**Через браузер**
 
Просто откройте адрес выше в браузере. Если сервер работает, увидите текст:
 
```
Сервер жив и слушает порт 8080!
```
 
**Через терминал (curl)**
 
```bash
curl -i http://51.250.38.122:8080
```
 
Ожидаемый ответ:
 
```
HTTP/1.1 200 OK
Content-Type: text/plain; charset=utf-8
 
Сервер жив и слушает порт 8080!
```
 
**Через JavaScript (fetch) — если хотите вызвать из своего фронтенд-кода**
 
```javascript
fetch("http://51.250.38.122:8080")
  .then((response) => {
    if (response.ok) {
      console.log("✅ Сервер доступен");
    } else {
      console.log("⚠️ Сервер ответил с ошибкой:", response.status);
    }
    return response.text();
  })
  .then((text) => console.log(text))
  .catch((error) => {
    console.error("❌ Сервер недоступен:", error);
  });
```
 
## Как трактовать результат
 
| Что видите | Что это значит |
|---|---|
| `200 OK` + текст "Сервер жив..." | Сервер работает, сеть в порядке. Если ваш фронтенд всё равно не получает данные — проблема в основном приложении (эндпоинтах, CORS, логике), не в сети |
| Запрос "висит" и не отвечает (таймаут) | Сервер выключен, либо порт закрыт в файрволе — не проблема фронтенда, нужно сообщить бэкенд-команде |
| `Connection refused` | На порту 8080 никто не слушает — сервер полностью выключен |
| CORS-ошибка в консоли браузера | Сервер отвечает, но не разрешает запросы с вашего домена — это отдельная настройка на сервере, тоже нужно сообщить бэкенд-команде |
 
## Важно
 
Это **временный тестовый эндпоинт**, а не часть основного API конструктора аватарок. Он предназначен только для проверки сетевой доступности сервера. Реальные эндпоинты приложения (генерация аватарок и т.д.) будут задокументированы отдельно, когда основное приложение будет задеплоено.
 
## Код скрипта (для справки)
 
```python
from http.server import HTTPServer, BaseHTTPRequestHandler
 
class Handler(BaseHTTPRequestHandler):
    def do_GET(self):
        self.send_response(200)
        self.send_header("Content-Type", "text/plain; charset=utf-8")
        self.end_headers()
        self.wfile.write("Сервер жив и слушает порт 8080!".encode("utf-8"))
 
if __name__ == "__main__":
    server = HTTPServer(("0.0.0.0", 8080), Handler)
    print("Слушаю на 0.0.0.0:8080 ...")
    server.serve_forever()
```
 
Скрипт запускается на сервере командой `python3 test_server.py` и продолжает работать, пока терминал открыт (или как systemd-сервис, если нужен постоянный health-check).
