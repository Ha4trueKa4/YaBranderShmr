#### Android project

Конструктор аватарок для рабочих чатов, визиток и профилей

#### Задача

Онлайн-сервис для быстрого создания аватарок, бейджей и изображений профиля в едином стиле для команд, мероприятий, курсов и сообществ.

#### Суть проблемы

Небольшая по масштабу, но очень “живая” тема, которую легко сделать красивой, полезной и понятной даже без сложной предметной области.

#### Возможное (готовое) решение

Веб-сервис/приложение

#### Ожидаемый результат

Запущен сервис
