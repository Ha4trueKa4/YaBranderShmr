# Локализация

Английская фраза является ключом и значением по умолчанию. Оборачивайте любой пользовательский текст в `t()`:

```tsx
const { t } = useTranslation()

<button>{t('Save')}</button>
```

При языке `en` фраза останется `Save`, а при `ru` будет взят перевод из тематических файлов в `ru/`.

Чтобы добавить новую строку, добавьте английскую фразу в JSX через `t()` и её перевод в подходящий файл из `ru/`. Не изменяйте английский ключ без одновременного обновления перевода.

Файлы разделены по области интерфейса:

- `common.json` — общие действия и подписи;
- `auth.json` — вход, регистрация и проверка полей;
- `projects.json` — проекты, профиль, лента и подписки;
- `editor.json` — редактор, генерация и экспорт;
- `errors.json` — общие ошибки загрузки и API.

Все части объединяются в `src/i18n.ts`, поэтому ключи остаются короткими: `t('Save')`, а не `t('common.Save')`.

Переключение языка:

```tsx
const { i18n } = useTranslation()

void i18n.changeLanguage('en')
```
