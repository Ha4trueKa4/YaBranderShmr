## Проверки после изменений

- После крупных правок обязательно запускать `pnpm check`.
- `pnpm check` проверяет TypeScript и Biome lint по исходникам.
- При необходимости проверить только форматирование запускать `pnpm format:check`.
- Если изменения затрагивают Vite-конфигурацию, зависимости или сборку, дополнительно запускать `pnpm build`.
- В отчёте указывать результат проверок и отдельно отмечать ошибки окружения, если команда не может выполниться.

## Публичные экспорты

- Через публичный `index.ts` экспортировать только части модуля, которые действительно нужны внешним потребителям и составляют его публичный контракт.
- Внутренние реализации, вспомогательные функции и детали конкретных слоёв не реэкспортировать: импортировать их только внутри модуля по относительному пути.
